# Brasa & Ponto — delivery app

## Implementado
- [x] Cliente vê somente navegação de pedidos/cardápio/ofertas; nenhum link da equipe aparece na vitrine.
- [x] O endereço de acesso dedicado aguarda definição do proprietário; a gestão de perfis permanece privada no painel.
- [x] Proprietário: financeiro, cardápio, configurações e gestão de perfis.
- [x] Funcionário: fila e detalhes de pedidos, status e observação interna; sem financeiro, catálogo, configurações ou gestão de equipe.
- [x] Demonstração de açaí, sucos naturais e marmitex com fotos hospedadas.
- [x] Testes de autorização para usuário, funcionário e proprietário.

## Para o proprietário
1. Defina e informe o link específico que deseja usar para a área da equipe.
2. Conecte esse endereço à rota autenticada da equipe e compartilhe-o com o funcionário.
3. A pessoa deve entrar uma vez usando a própria conta.
4. Em Equipe, mude seu perfil para “Funcionário · pedidos”.
